## 一、整体策略总览

### 1.1 30 天目标定位

本月不追求"成交"，追求 **"合格询盘"** 进入到工程评估/报价阶段。OEM 笔记本采购周期 1–6 个月，30 天属于"播种 + 发芽"阶段，目标是把 **询盘漏斗顶端建立起来**：

| 阶段 | 30 天目标量级 |
|---|---|
| 网站合格 UV（B2B 流量） | 1,500–3,000 |
| 合格询盘（含表单/邮件/Telegram/Linkedin DM） | 15–30 条 |
| 进入报价的"工程评估级"询盘 | 5–10 条 |
| 进入样机阶段 | 1–3 条 |

合格询盘定义：**有公司名 + 国家 + 品类需求（笔记本/迷你主机/游戏本）+ 预计 MOQ 或采购数量描述**，四项至少占三项。

### 1.2 N+1 引流模型

- **"1" = 官网 aierxuanlaptop.com**：所有外部流量最终落点，承担"信任建立 + 询盘转化"。
- **"N" = 多渠道分发**：每个渠道扮演不同角色——
  - 搜索引擎（Yandex/Google）= 主动需求拦截
  - LinkedIn/Telegram/邮件冷启 = 主动触达决策人
  - B2B 平台（阿里国际站/MIC/EC21/Europages/Kompass）= 平台内 RFQ 截流
  - 内容/YouTube/博客 = 信任背书 + SEO 长尾
  - 行业目录 = 被发现 + 反链

### 1.3 三市场差异化主线

| 市场 | 主线 | 主推产品组合 | 关键合规 |
|---|---|---|---|
| 俄罗斯（已启动） | Yandex 搜索 + Telegram 直营 + 俄语本地化 | Aierxuan 商务本 + Game Soul 游戏本（卢布性价比敏感） | EAC 认证、卢布报价、Bitrix24 询盘流 |
| 欧洲（DACH/西欧/CEE，本月启动） | Google Ads + LinkedIn + Europages/Kompass | 商务本 + 迷你主机（B 端办公采购） | CE/UKCA/RoHS、VAT、Incoterms DDP/CIF |
| 日本（本月调研启动，下月正式投放） | 商社/代理优先 + LinkedIn + 日文 LP | 迷你主机（嵌入式/工控）+ 商务本 | PSE 认证、日文化、礼仪邮件、JET 测试 |

## 五、三市场差异化打法

### 5.1 俄罗斯（主战场，已启动）

- **搜索引擎**：Yandex 主，Google 次（俄罗斯 Yandex 市占约 60%，Google 约 35%）。Yandex Direct + РСЯ（展示网络）双轨。
- **社交直营**：Telegram @aierxuan_russia 持续运营，是俄罗斯 B2B 沟通的事实标准。每周 4–6 条内容，2 条产品 + 2 条工厂 + 1–2 条认证/案例。
- **合规重点**：**EAC 认证** 是进入俄罗斯/EAEU 海关的硬门槛；网页和广告里要强调"EAC ready / EAC certified"。
- **报价 + 支付**：默认提供卢布 + 美元双报价（或 USD 报价 + 卢布参考价）；支持人民币结算给俄方进口商。Incoterms 主推 CIF 圣彼得堡 / DAP 莫斯科。
- **CRM**：Bitrix24（俄罗斯主流 B2B CRM）做询盘流转，也方便后续给俄方代理交接。
- **本地化**：俄语 LP + 俄语博客 + 俄语客服模板；避免机翻味（关键词如 "ноутбук оптом / OEM ноутбук / мини-ПК OEM Китай"）。
- **代理网络**：在 4PDA / Habr / VC.ru 找硬件分销商/集成商社区，软性互动（非硬广），积累私信线索。

### 5.2 欧洲（DACH + 西欧 + CEE，本月新启）

- **搜索引擎**：Google 主（市占 90%+），分德/法/西/波/意 5 国分别建广告组。
- **LinkedIn**：欧洲 B2B 决策者重度使用 LinkedIn。Sales Navigator 锁定 "Procurement Manager / Product Manager / Hardware Buyer / Electronics Distributor"，公司规模 50–500 人优先。
- **合规重点**：**CE / UKCA / RoHS / WEEE** 必须明示；增值税 **VAT 反向收费（reverse charge）** 在 B2B 场景默认操作，但要在报价里写清楚。Incoterms 推 **DDP**（DDP 对采购方最省心，更易拿单）或 **CIF**。
- **行业目录**：Europages 免费版 + Kompass + EuropeBusinessDirectory。这些目录的反向链接对 Google SEO 有溢出效应。
- **多语言**：优先级 EN > DE > FR > PL > IT。DE/FR 的产品页可先翻译商务本 + 迷你主机两个核心品类，游戏本第二轮。
- **冷启邮件**：用 Hunter/Apollo 拉欧洲 ICP，邮件主题用本地语言（DE/FR 主题行的回复率比纯 EN 高 1.5–2 倍）。
- **展会信息（下月规划）**：IFA Berlin（9 月）、Embedded World Nuremberg（明年 3 月）—— 本月先做调研，看是否参展或只去观展。

### 5.3 日本（本月调研期，下月正式投放）

- **代理优先**：日本 B2B 笔电采购高度依赖商社/代理（如双日、三井物产、丸红等），中小代理也很多。本月目标是 **建立第一批联系名单**，而非直接卖给终端用户。
- **认证**：**PSE 圆形/菱形** 是日本电器进口必备，电池 PSE 单列；广告和 LP 要明确标注 PSE 状态（已认证 / 可申请协助）。
- **B2B 平台**：NC Network（日本制造业 B2B 主流）、Mitsuwa、イプロス（ipros.jp）。本月先注册 + 写主页，下月起跑。
- **LP 调性**：日文 LP 风格要"沉稳、低饱和、信息密度高"；避免欧美式 hero banner 大字号促销风。技术规格表、认证书扫描件、可追溯的工厂资质比"性价比"更打动日本买家。
- **沟通礼仪**：邮件用 「お世話になっております」开头，附"会社案内.pdf"（公司简介日文版）；不要在第一封邮件谈价格，先建立信任。
- **首批 LP 产品**：迷你主机系列（工控/嵌入式用途）+ 商务本（轻薄长续航 SKU），暂不主推游戏本（日本游戏本市场偏品牌化，OEM 切入难）。

## 六、风险与未确定项（需老板确认）

1. **预算审批**：月度建议 $1,610–$3,180 是否在可批范围？广告 + 平台账号 + 工具订阅至少需要 $1,200 才能跑起来；低于此预算需要砍掉一个市场（建议砍日本调研 + 缩 LinkedIn Sales Nav）。
2. **人力配置**：本规划默认 **1 人全职 + 必要的中文翻译/设计支持**。如果只有兼职 50% 投入，需要把任务量砍 40%，建议保留俄罗斯 + 欧洲，砍日本。
3. **认证状态**：EAC（俄）、CE/UKCA（欧）、PSE（日）目前 **实际持有情况** 必须老板提供清单。如果某类认证缺失，对应市场广告文案不能宣称"已认证"，否则法务风险。
4. **MOQ 策略**：21 款 SKU 的 **官方 MOQ** 是否统一公开？建议公开"询价起订量"区间（如 50–100 台起谈），不公开实际底价。需老板确认能否在产品页公开 MOQ 区间。
5. **报价/打样响应 SLA**：B2B 采购最在意"多久回报价"。建议承诺 **24 小时内首次回复 + 72 小时内详细报价 + 7–14 天样机**。需老板确认能否兑现。
6. **CRM 选型**：Bitrix24（俄市偏好）vs HubSpot Free（欧美偏好）vs Notion（轻量）—— 三选一。建议本月先用 Notion 数据库过渡，下月迁移到 Bitrix24（俄市优先）。
7. **工厂照片/视频版权**：是否有可公开发布的工厂走访素材？如果没有，需要 1–2 天拍摄安排，否则信任要素弱。
8. **样机寄送预算**：B2B 询盘进入"打样阶段"后，样机寄送（含 DHL/FedEx 国际快递）需要预算和审批流程，建议预留 $500–1,000 月度样机预算。
9. **多语言翻译质量**：俄/德/日的关键页面建议至少过一遍 **母语者校对**（Fiverr/ProZ 单页 $20–50），机翻易丢信任。
10. **Telegram 群组运营人力**：俄语日常互动需要至少能读懂俄语的人（机翻 + 校对也可），需明确是老板亲自回还是配人。
