## 一、整体策略与询盘漏斗

### 1.1 询盘三层口径（v1 修订：消除 KPI 打架）

| 漏斗层 | 定义 | 月度目标 |
|---|---|---|
| L1 原始 lead（raw） | 表单/邮件/IM 任何留资，含垃圾 | 50–80 |
| L2 合格询盘（MQL） | 公司名 + 国家 + 品类 + MOQ 或数量描述（四占三）| **15–30** |
| L3 报价级（SQL） | 进入正式报价 + 需要样机或参数评估 | 5–10 |
| L4 样机阶段 | 已寄样或确认参数定制 | 1–3 |

**单一口径承诺：本计划所有"询盘"默认指 L2。各渠道目标按 L1（原始）口径估算，月底统一过滤为 L2。**

### 1.2 N+1 引流模型

- **1 = 官网 aierxuanlaptop.com**：唯一询盘落点，承担信任建立 + 转化。
- **N = 多渠道**：
  - 搜索（Yandex/Google）= 拦截主动需求
  - LinkedIn/Telegram/邮件 = 主动触达决策人
  - B2B 平台（阿里/MIC/Europages/ipros.jp/NC Network）= 平台 RFQ
  - 内容/YouTube/拆机评测 = 信任背书 + 长尾 SEO
  - 行业目录 = 反链 + 被发现
  - 老客户转介绍 = 高转化补充

### 1.3 三市场差异化主线

| 市场 | 主线 | 主推 SKU | 合规硬门槛 |
|---|---|---|---|
| 俄罗斯（已启动） | Yandex 搜索 + Telegram + 俄语本地化 + EAC | Aierxuan 商务本 + Game Soul 游戏本 | TR CU 004/020 + TR EAEU 037 + 含 Wi-Fi/BT 需 FSB 加密通知 |

### 3.3 老板视角解读（Gemini 反馈）

- Schema 标记 = 让 Google/Yandex 抓取得更准、显示得更显眼的"代码身份证"
- Pmax / РСЯ = 用 AI 在搜索之外的版面（视频、Gmail、合作站）拦截可能漏掉的客户
- GA4 keyevent = 精确监控有几个客户按了"发送询盘"按钮
- hreflang = 告诉搜索引擎"这页是俄语版/英语版"，避免拿错语言版本去匹配错市场用户
- CPL = 平均花多少美元拿到 1 条原始留资；真正衡量广告 ROI 的硬指标
- DDP / CIF / FOB = 谁付海运、关税、清关；DDP = 我方全包到买家门口，欧洲客户最爱

## 五、三市场差异化打法（颗粒度对齐）

### 5.1 俄罗斯（主战场，已启动）

- **搜索**：Yandex 主（StatCounter 2026-04: **73.12%**，不是 60%）。Yandex Direct + Wordstat 长尾 + Metrica 转化；РСЯ 展示网络 CTR 基线低（0.3–0.8%），谨慎开。
- **社交**：Telegram @aierxuan_russia 持续运营（俄 B2B 沟通事实标准），每周 4–6 条；找 1 位 4PDA/iXBT 系硬件 YouTuber 拆机/散热互推。
- **合规（v1.1 拆细）**：
  - **EAC declaration vs certificate** 区分；
  - **TR CU 004/2011（低压）+ TR CU 020/2011（EMC）+ TR EAEU 037/2016（RoHS）** 三件套对应；
  - 含 Wi-Fi/Bluetooth 必须做 **FSB encryption notification**（俄罗斯 FSB 加密通知）；
  - 含美国芯片需评估 **EAR/BIS** 再出口管制 + 终端用户筛查（OFAC SDN）。
- **报价支付**：USD 报价 + 卢布参考价；CIF 圣彼得堡 / DAP 莫斯科主推；支持人民币结算。
- **CRM**：Bitrix24 俄市友好。
- **本地化关键词**："ноутбук оптом / OEM ноутбук Китай / мини-ПК промышленный / OEM лаптоп производитель"，避免机翻味。
- **代理网络**：4PDA / Habr / VC.ru 软互动 + 私信线索。

### 5.2 欧洲（DACH + 西欧 + CEE，本月新启）

- **搜索**：Google 主（StatCounter 2026-04 ~**87.5%**，不写 90%+）。德/法/西/波/意 5 国分语种广告组。
- **LinkedIn**：B2B 决策者重度使用。Sales Navigator **Core 官价 $119.99/月**（不是 $80）；ICP：Procurement Manager / Product Manager / Hardware Buyer / Electronics Distributor，公司 50–500 人。
- **合规（v1.1 拆细）**：
  - **CE 标识 = EMC（2014/30/EU）+ LVD（2014/35/EU）+ RED（含无线时 2014/53/EU）+ ErP（能效）**；
  - **RoHS（2011/65/EU）+ REACH（SVHC 申报）**；
  - **WEEE 不是证书，是生产者责任注册** —— 各国独立注册（DE: stiftung-ear / FR: ADEME / IT: RAEE / PL: BDO 等），由进口方或我方代为注册；
  - **UKCA**：英国市场，2026 仍承认大量产品的 CE 标识，无需重复双标；
  - **VAT**：B2B 反向收费默认，需在 invoice 明确 reverse charge note；
  - **Incoterms**：DDP 最有竞争力（含关税/VAT），CIF 备选。
- **目录**：Europages 免费 → 一档付费 $200；Kompass；EuropeBusinessDirectory；**不投 ThomasNet（北美）**。
- **冷启邮件合规**：
  - **GDPR Art.6(1)(f) 合法利益判断**（B2B 可用）；
  - **PECR（英国电子营销条例）**：B2B 邮件需明确身份、退订、联系方式；
  - 维护 **反对名单（do-not-contact list）**；
  - **SPF + DKIM + DMARC** 在发件前 100% 配齐。
- **多语言**：EN > DE > FR > PL > IT。DE/FR 主题行回复率比 EN 高 1.5–2x。
- **展会（v2 评估）**：IFA Berlin（9 月）、Embedded World Nuremberg（明年 3 月）。

### 5.3 日本（调研期，下月正式投放）

- **代理优先**：日本 B2B 笔电高度依赖商社/代理（双日/三井物产/丸红/伊藤忠的电子部门 + 中小代理）；本月建立第一批联络名单，不直卖。
- **合规（v1.1 拆细）**：
  - **PSE 不能笼统说"日本电器必备"**：METI 英文指南显示 notebook PC 主机本体不一定列入 Electrical Appliances and Materials；
  - **强相关项**：随附 **AC/DC 适配器（PSE 菱形/圆形按结构）** + **二次锂电池（PSE 菱形 + UN38.3 + MSDS）**；
  - **含 Wi-Fi/Bluetooth**：日本 **MIC 技适（TELEC/JATE）** 必备。
- **B2B 平台**：**ipros.jp（イプロス）+ NC Network**；删除 v1 中的 Mitsuwa（无明确依据）；日経 BP / xTECH 属媒体广告位非 B2B 目录，本月不投。
- **LP 调性**：日文 LP 沉稳、信息密度高、技术规格表 + 认证扫描件 + 工厂资质，避免欧美 hero banner 大字促销风。
- **沟通礼仪**：
  - 邮件首句「いつもお世話になっております」/ 初次「お初めまして、AIERXUAN の[Name]と申します」；
  - 首封必附 **会社案内.pdf**（日文版公司简介，4–6 页）；
  - 首封不谈价，先建立信任 + 强调"PSE 合规协助 + 长期主义 + 严苛品控"。
- **首批 LP 产品**：迷你主机（工控/嵌入式）+ 商务本（轻薄长续航），暂不主推游戏本（日本游戏本市场品牌化深，OEM 难切入）。
- **展会（v2 评估）**：CEATEC（10 月）、Japan IT Week（春/秋）。

## 七、风险与待决策项（v1.1 扩展）

### 7.1 老板必须确认（影响计划可执行性）

1. **预算审批**：建议范围 **$2,200–3,800**（v1.1 修正后），最低红线 **$1,400**。低于红线需砍日本调研 + Europages 付费 + LinkedIn Sales Nav + YouTube 寄样。
2. **人力配置**：1 人全职 + 中文翻译/设计支持。50% 兼职需把任务砍 40%（保俄+欧、砍日）。
3. **认证实际持有情况**：v1.1 SKU 认证矩阵 W1 Day 1 必须由老板提供数据填实；缺什么直接影响广告/LP 文案能否宣称"已认证"（虚假宣传法务风险）。
4. **MOQ 公开策略**：是否在产品页公开 MOQ 区间（建议公开 50–100 台起谈，不公开底价）。
5. **报价/打样 SLA**：承诺 24h 首回 + 72h 详细报价 + 7–14 天样机能否兑现。
6. **CRM 选型**：Bitrix24（俄市友好）/ HubSpot Free（欧美）/ Notion（轻量过渡）；建议 W1 用 Notion 过渡 → W4 决定迁移目标。
7. **工厂照/视频版权**：能否安排 1–2 天产线拍摄，否则信任要素链路断。
8. **样机预算**：B2B 询盘到打样阶段 DHL/FedEx 国际快递 + 锂电池危险品申报，建议预留 $500–1,000/月。
9. **翻译质量**：俄/德/日母语校对 $20–50/页，是否批 $200–400/月翻译预算。
10. **Telegram 俄语回复人力**：老板亲自回还是配人？
11. **出口管制（v1.1 新增）**：21 款 SKU 是否含 **美国芯片 / Wi-Fi/BT 无线模块**？涉及 EAR/BIS 再出口管制 + 俄罗斯终端用户筛查（OFAC SDN），需法务把关。
12. **展会决策（v1.1 新增）**：2026 ExpoElectronica（俄）/ IFA / Embedded World / CEATEC / Japan IT Week 是否报名？影响 W4 的下月 v2 规划。
13. **老客户转介绍 SOP（v1.1 新增）**：是否启用 2% 折扣 / 5 台备品的转介绍激励？

### 7.2 风险清单

- **合规风险**：宣称未持有的认证 = 法务风险。
- **数据归因风险**：UTM/CRM 不在 Day 1–2 完成 → 前两周流量"黑盒"，无法判断 ROI。
- **任务量风险**：1 人 4–6h/天 × 21 SKU × 3 市场 × 10+ 渠道，**真实超载**。建议优先级：俄罗斯 > 欧洲 > 日本（日本可推到下月）。
- **CPL 现实风险**：B2B 笔电 OEM 真实 CPL 区间 $60–150，远高于 D2C；老板心理预期需对齐。
- **冷启邮件 GDPR 风险**：未配 SPF/DKIM/DMARC + 退订机制就群发 → 列入黑名单 + 法务风险。
