# AIERXUAN 21 款 SKU 认证矩阵（模板 · 待老板回填）

> 版本：TEMPLATE v1｜日期：2026-05-31｜责任：运营建模板 → **老板回填真实认证状态** → 运营据此定广告/LP 文案口径
> 用途：决定每款 SKU 在俄/欧/日三市场"能不能宣称已认证、能不能上架、广告文案能不能写"。
> **合规红线：未持有的认证绝不能在 Listing/广告/LP 宣称——虚假宣传在海外法务风险远高于国内。缺证的市场，文案只能写「可协助申请」。**

---

## 一、填写说明（老板/合规必读）

每个单元格填以下状态之一：

| 符号 | 含义 | 文案可否宣称 |
|---|---|---|
| ✅ | 已持有有效证书/声明，有编号可查 | 可宣称"已认证"，并在 RFQ 附扫描件 |
| ⏳ | 申请中 / 可快速申请 | 只能写"可协助申请 / 申请中"，不可写"已认证" |
| ❌ | 未持有、暂无计划 | 不可提及该认证；对应市场谨慎上架 |
| N/A | 该 SKU 结构不涉及此认证 | 标注原因（如无无线模块则 RED/FSB/技适 N/A） |

**回填要点**：
1. 把下方占位型号（SKU-A01…A10 / SKU-G01…G11）换成 21 款真实型号名（如已知一款 `Air15 N5095`）。
2. 每个 ✅ 后用括号补证书编号或发证机构（例：`✅(CE-DoC #2026-xxx, TÜV)`），方便 RFQ 引用。
3. 含 **Wi-Fi/蓝牙无线模块** 的 SKU 必须单独标记（影响 RED / 俄 FSB 加密通知 / 日本 MIC 技适三项）。
4. 含 **美国芯片** 的 SKU 单独标记（触发 EAR/BIS 再出口管制 + 俄 OFAC SDN 终端筛查，需法务把关）。
5. **适配器 / 锂电池认证与主机分开填**（PSE、UN38.3、MSDS 通常挂在适配器/电池上，不是主机本体）。

## 四、回填后运营怎么用（联动 RFQ/广告/LP）

1. **市场放行三色**：某 SKU 在某市场的"主机必需认证"全 ✅ → 该市场可主推、广告可宣称；有 ❌ → 该市场降级或文案改"可协助申请"。
2. **广告/LP 文案门**：LP 上的"CE certified / EAC ready / PSE 适配"等字样，必须能在本表找到对应 ✅，否则删字或改措辞。
3. **RFQ 响应包**：买家要认证扫描件时，按本表 ✅ 单元格的编号调取，缺的明确告知"申请周期 X 周"。
4. **出口管制**：任一"含美国芯片?=是"且目标=俄罗斯 → 走法务 EAR/BIS + OFAC SDN 终端用户筛查流程后再报价。
